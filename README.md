# Credit Card Fraud Detection Using Hybrid Anomaly Detection

## Project Overview

An advanced machine learning system for detecting suspicious credit card transactions using multiple anomaly detection techniques.

## Detection Techniques

- Isolation Forest
- Local Outlier Factor
- One-Class SVM
- Autoencoder
- Hybrid Anomaly Detection

## Technology Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- TensorFlow
- FastAPI
- PostgreSQL
- React
- Docker

## Project Goal

The system analyzes credit card transactions, detects anomalous behavior, generates a risk score, and provides explainable fraud alerts through a real-time dashboard.
